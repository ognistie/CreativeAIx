# POL-011 — Claude Code e Codex só quando a pessoa os chama

> [!policy] Regra
> Um plano só usa o agente [[ExtCode Agent]] (Claude Code ou Codex) quando o pedido da pessoa cita a ferramenta pelo nome ("com o Claude", "pelo Codex") ou ela foi escolhida no composer (`/claude`, `/codex`). Pedido de ler, revisar ou analisar arquivos é respondido pela conversa, com as ferramentas só de leitura; pedido de ação sem a ferramenta citada segue pelos agentes do app.

- **Aplicação:** bloqueia (o plano é reprovado e o Maestro replaneja uma vez com o motivo)
- **Validada por:** [[Maestro]] (`core/plan_validator.py` → `validate_plan`); a conversa também recusa um pedido de ação que cite a ferramenta quando a mensagem atual não a cita (`agents/chat_agent.py` → `handoff_error`)
- **Origem:** incidente de 2026-11-24: "faça uma análise no código da plataforma" virou tarefa do Claude Code sem ninguém pedir e falhou na pasta do próprio app
